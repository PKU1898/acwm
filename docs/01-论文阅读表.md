# 论文阅读表

每周 3 篇，读完就填。**"与我的关系"这一列最重要**——它决定这篇是基线、对标还是背景。

## 表头（复制到 Notion / 飞书 / Excel 都行）

| 标题 | 年份 | Venue | 核心做法（1–2 句） | 可复现性 | 与我的关系 | 吐槽 / 缺口 | 链接 | 读毕 |
|---|---|---|---|---|---|---|---|---|
| ... | ... | ... | ... | 官方代码 / 数据齐全 / 只有权重 / 无 | 基线 / 对标 / 背景 / 直接竞争对手 | ... | ... | 日期 |

- **可复现性**：官方代码 ✅/❌ · 数据集公开 ✅/❌ · 依赖是否还装得上
- **与我的关系**：
  - 基线 = 我要在论文里对比它
  - 对标 = 我的方法要号称优于它
  - 直接竞争对手 = 有人在做和我一样的事，必须划界（⚠️ 发现这种要立刻深挖）
- **吐槽 / 缺口**：它没做什么、它假设了什么、哪里可以攻击。**这一列是创新点的来源**
