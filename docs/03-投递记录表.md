## 每周必做

- [ ] 每周投 **3–5 家**（W4–5 那周投 20–30 家）
- [ ] 每周复盘一次：哪种渠道回复率最高？反复被问到的问题是什么？
- [ ] **被问倒的问题 → 当天写进学习清单**，下一轮面试前必须补上

## 识别"伪装成算法的数据岗"

JD 里高频出现这些词 = 数据或工程岗，**不投**：

> 标注 / 清洗 / 采集运营 / 数据开发工程师（大数据方向）/ Spark / Ray / 数据湖 / Golang 后端 / 离线数仓

上海 AI Lab 里明确**不投**的：具身仿真数据实习生（工程通道）。

## 内推优先级（远高于海投）

1. 牛客搜「具身 内推」「智元 内推码」「银河通用 内推」
2. 小红书搜「公司名 + 内推」
3. **给目标团队的开源项目提 PR，然后私信 maintainer** —— 这个转化率最高，还能顺便证明工程能力
